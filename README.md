# Pr16Avalonia — «Подземелье»

Пошаговая RPG с графическим интерфейсом на Avalonia (практическая работа №16, группа 3ИСИП-323).

## Об игре

Герой спускается в подземелье, и каждый ход случайно выпадает событие:

- **Сундук** — меч или броня со случайным бонусом. Найденный предмет можно взять или оставить.
- **Бой** — один противник или группа из 2–3 врагов. Доступны атака и защита.
- Каждый 10-й ход — **босс**.

Противники: слизь, гоблин, маг, скелет. Боссы: «ВВГ Гоблин-Босс», «Архимаг C++», «Скелет-Ковальский» и другие.

В интерфейсе: главное меню, полосы здоровья и этажа, инвентарь, лог боя, картинки противников.

## Структура

- `Pages/FirstPage` — главное меню;
- `Pages/GamePage` — игровой экран;
- `Enemy/` — игрок, враги, боссы, фабрика монстров `MonsterFabric` и игровая логика `Game`.

## Технологии

- C#, .NET 9
- Avalonia 11
- WpfLikeAvaloniaNavigation (навигация по страницам)

## Запуск

```bash
dotnet run --project Pr16Avalonia
```
